How a donation moves

Both sides see every step, from posted to collected.

  1. PostedThe hotel lists what's left, with a safe-until time.
  2. RequestedA recipient asks for a number of servings.
  3. ConfirmedThe hotel says yes and the recipient gets a one-time code.
  4. CollectedThe recipient shows the code at pickup. Done.
